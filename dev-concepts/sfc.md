# Single-File Component (SFC)

---

In web development, **SFC** most commonly stands for **Single-File Component** (popularized by [Vue.js](/javascript/web-development/frontend/vue/vue-knowledge/_about.md)). An SFC bundles a component's markup, logic, and styling into a single file (such as `.vue` or `.svelte`) rather than splitting them across separate HTML, JavaScript, and CSS files.

---
## Core Parts of a Vue SFC (`.vue`):
- **`<template>`:** Defines the HTML structure and declarative UI bindings.
- **`<script>`:** Holds component state, props, lifecycle hooks, and logic (often using `<script setup>`).
- **`<style>`:** Defines CSS; adding `scoped` limits styles to that specific component.
