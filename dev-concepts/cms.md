# CMS: Content Management System

---

It's a software that lets you create, manage, and modify content on a website without needing technical web development skills.

Instead of writing code (like HTML, CSS, or JS) from scratch to build pages and publish articles, a CMS provides an intuitive interface to manage the web application images, text, documents, users, etc.
