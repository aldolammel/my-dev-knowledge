#### Dev concepts
# Seeding / Database Auto-Seeding (Mock & Initial Data) / Auto-populating

---

In Web Frameworks and ORMs (e.g., Prisma, EF Core, Laravel Eloquent, Django), auto-seeding is the process of automatically populating a fresh database with default or dummy data when running migrations or starting up an application environment (development/testing).

- **Initial Data:** Populating default roles, lookup tables, or admin users during setup.
- **Test Data:** Using libraries like Faker to automatically generate thousands of mock records when running automated test suites.
