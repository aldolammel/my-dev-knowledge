# Rebuild/Re-sync project's Node dependencies

---

==REMEMBER:==
The Node.js itself will be untouchable! No worries.

---
## Before:
1. Assuming this project's dependencies/components have been installed without global flags like the `-g` for `npm`.
2. Make sure you are in the Node project's folder (where you find the `/node_modules/` folder is).

---
## 1) Make sure your `package.json` is on the project's folder and updated!
The `package.json` file must be in the same folder level of the `/node_modules/` folder.

---
## 2) Delete the old project's Node dependencies:
```bash
rm -rf node_modules package-lock.json
```

---
## 3) Re-sync `/node_modules/` folder:
Based on what is declared in `package.json`:

Using NPM:
```bash
npm install
```
