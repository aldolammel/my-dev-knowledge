......................................

### A) Semi-automatic, using `.nvmrc` file

A.1) On terminal, no matter where you are, check the current Node versions installed:
```bash
node --version
# Or all local available ones:
nvm list node
```

A.2) Go to the project folder (back-end).

A.3) Create the `/frontend/.nvmrc` file:
```bash
echo "<version>" > .nvmrc   # "26.13.1"
# To edit that file (if needed):
nano .nvmrc
```

A.4) From now on, always you get in the project folder, run this to automatically select the right Node.js version: [javascript/web-development/backend/nodejs/activating-node-specific-version](javascript/web-development/backend/nodejs/activating-node-specific-version.md)
