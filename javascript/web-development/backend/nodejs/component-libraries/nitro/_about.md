# Nitro (Server Engine & Toolkit)

---

Nitro is a server framework built on top of runtimes like [Node.js](javascript/web-development/backend/nodejs/_about.md) (most common option). Created to power [Nuxt](/javascript/web-development/frontend/vue/3-component-libraries/nuxt/_about.md), it provides high-level web server features like file-based routing, caching, and API handling
