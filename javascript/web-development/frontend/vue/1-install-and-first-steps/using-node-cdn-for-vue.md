# Using Node via CDN

---

==ARE YOU SURE?==

You'll need Node.js if you want:
- SFC (.vue files with templates, script, and style in one file).
- Build tools like Vite, Webpack, or Vue CLI for optimization.
- TypeScript support with proper compilation.
- Server-Side Rendering (SSR) with frameworks like Nuxt.
- Modern tooling for testing, linting, and production optimization.
- Package management to install third-party Vue libraries.

==CAUTION!==
With CDN, you must define your components as JS objects 'coz browser doesn't understand `.vue` files.
