# Project approach: SPA vs MPA

---
## Single-Page-Application (SPA):
- One main HTML entry point.
- Vue manages navigation using Vue Router.
- Data is requested from Django through APIs.
- Most navigation happens without reloading the page.
- Poor compatible with SEO.
- Poor compatible with link previews (sharing content).
## Multi-Page-Application (MPA):
- Multiple HTML pages.
- Back-end language you are using renders HTML for each page.
- Navigation generally requests a new page from the server.
- Vue can enhance individual pages, but doesn't own the entire application.
- Full compatible with SEO.
- Full compatible with link previews (sharing content).
