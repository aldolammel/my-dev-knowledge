## 1) Running:
For Vue project built by Vite:
```bash
# Using NPM:
npm run dev
# Using YARN:
yarn dev
```
For Vue project built by [Vue-CLI](/javascript/web-development/frontend/vue/build-tools/vue-cli/_about.md) (default):
```bash
# Using NPM:
npm run serve
# Using YARN:
yarn serve
```
