## 1) Running:

**Before:**
- For Node locally, active the project's Node case it's not automatic:
```bash
nvm use
```

**1.1) Running it:**

For Vue projects built by Vite:
```bash
# Using NPM:
npm run dev
# Using YARN:
yarn dev
```

For Vue projects built by Vue-CLI (default):
```bash
# Using NPM:
npm run serve
# Using YARN:
yarn serve
```
