#### JavaScript > Front-end > Vue
# Initial development roadmap

---
## Before:
- Assuming your project already has its `/frontend/` folder structured.
- Assuming your project has its [sitemap](/web-development/document-templates/sitemap.md) approved.
- Assuming your project has its art designs or, at least, its wireframes approved.
- Why NOT develop the ENTIRE front-end before back-end:
	- Authentication state.
	- User permissions.
	- Data availability.
	- Form validation responses.
	- API error handling.
