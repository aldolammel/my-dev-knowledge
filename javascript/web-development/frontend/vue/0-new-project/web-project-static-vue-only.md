# Vue-only project solution, completely static (no CMS, no database)

---

Even though Vue runs over Node.js that has the ability to store data, this roadmap goes in the simplest way possible to work with Vue benefits.

---
## Before:
At first, make sure the static solution is what your project need:
- Will the app receive a few updates throughout the year?
	- Forget the static solution, going to Vue-only solution but dynamic: [/javascript/web-development/frontend/vue/0-new-project/web-project-dynamic-vue-only](/javascript/web-development/frontend/vue/0-new-project/web-project-dynamic-vue-only.md)
- Will the app receive frequent updates throughout the year?
	- Forget the static or simple dynamic solution, you need a true back-end with [CMS](/dev-concepts/cms.md):
		- Using Python + Back-end Django: [/python/web-development/django/0-new-project/web-project-django-with-vue](/python/web-development/django/0-new-project/web-project-django-with-vue.md)
		- Using Python + Back-end Flask: [/python/web-development/flask/0-new-project/web-project-flask-with-vue](/python/web-development/flask/0-new-project/web-project-flask-with-vue.md)
		- Using Python + Back-end FastAPI: [/python/web-development/fast-api/0-new-project/web-project-fastapi-with-vue](/python/web-development/fast-api/0-new-project/web-project-fastapi-with-vue.md)
