LIBRARY: VUEX (Deprecated since 2025)

---

Vuex (the official solution for Vue 2) is a state management pattern + library for Vue.js apps that serves as a centralized store for all the components in an app, with rules ensuring that the state can only be mutated in a predictable fashion.

https://vuex.vuejs.org/

==IMPORTANT:==
Vuex was replaced by [Pinia](javascript/web-development/frontend/vue/component-libraries/pinia/_install.md) in Vue 3.

---
## 1) Installation:
To install:
```bash
npm install vuex@<version you want>
```
# Check the installation:
```bash
npm list
```
## To uninstall (if needed):
```bash
npm uninstall vuex@<version you want>
```
# Check removal:
```bash
npm list
```
