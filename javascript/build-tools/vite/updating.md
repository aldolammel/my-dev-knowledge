# Updating Vite

---
**Before:**
- On terminal, go to the front-end project folder.
- If you are using Vite globally (not recommended), do it anywhere but strongly recommended to [uninstall](/javascript/build-tools/vite/uninstall.md) it [and make it by project](/javascript/build-tools/vite/0-vite.md).

Updating to the latest version:
```bash
npm update vite
```
Or updating to a specific version:
```bash
npm install vite@6.3.5
```
Checking again the current Vite version:
```bash
npm list vite
```
