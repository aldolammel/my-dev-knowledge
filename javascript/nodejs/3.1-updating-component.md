# NPM: Updating Node components

---
## Before:
- Assuming you're on the terminal where the `/node_modules/` folder is (commonly in `/frontend/` root).
- (If applicable) Active the project Node version: [/javascript/nodejs/activating-node-specific-version](/javascript/nodejs/activating-node-specific-version.md)

---
## 1) Check project's node component updates:
Using NPM:
```bash
npm outdated
npm update --dry-run     # Nothing will be updated, no worries!
```

---
## 2) Update components:
Using NPM:
```bash
# All of them:
npm update
# Or a specific one (respecting rules from package.json):
npm update <package-name>
# Or a specific one with its latest version:
npm install <package-name>@latest
```
