## Choose what automation you wish:
- A) Semi-automatic, using `.nvmrc` file on each project folder (Faster, most common);
- B) Absolutely automatic, editing the `~/.bashrc` (Advanced);

......................................

### A) Semi-automatic, using `.nvmrc` file

A.1) Go to the project folder where you need Node.js (probably `/frontend/`).

A.2) Check the current Node installed:
```bash
node --version
```

A.3) Create the `/frontend/.nvmrc` file:
```bash
echo "<version>" > .nvmrc   # "26.13.0"
```

To edit that file (if needed):
```bash
nano .nvmrc
```

A.4) Now, always you get in the project folder, run this to automatically select the right Node.js version (but make sure you are in a updated terminal case you just installed the NVM):	
```bash
nvm use
```
