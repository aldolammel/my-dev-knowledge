#### OS > Linux
# Critical system folders

---

Linux brings a philosophy where there is no a centralized place for all apps. Instead, Linux uses a configuration structure by app, preventing all data to be stored in an exclusive database.

So Linux has a clear instruction about where those config files should home

---
## `/etc/`
- If an app has a global approach for all users, the app critical settings are found stored here.
## `/home/yourusername/.config/`
- If an app has configurations for a specific user, those instructions are found stored here.
