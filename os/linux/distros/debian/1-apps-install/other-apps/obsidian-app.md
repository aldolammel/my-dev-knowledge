How to config Obsidian App:

---
## Extension: Code Files by Lukas Bach

Should Open these file types:
```
ts,tsx,js,json,jsx,py,vue,html,css,scss
```

---
## Extension: Show All Hidden Files by Anatolii Kmetiuk

Should show files and folders that start with '.' (dot) too:

E.g. `.env`,  `.venv`.

## Obsidian repos:

Remember: for every new vault using repository, set it through the .gitignore file to never commit the `./obsidian/workspace.json` file. Leave it personal for every machine using the repo:
```
### Obsidian ###
.obsidian/workspace.json
```
