# Install the SASS/SCSS Compiler:

---
# Before:
- Make sure you are in the `/frontend/` folder.

---
## 1) Install the SASS/SCSS compiler:
It's install only for development environment!
```bash
npm install -D sass-embedded     # -D dev dependency!
```
Verify your SASS dependency in `package.json`!

---
## 2) (If applicable) If a `npm` warns something, you can ignore it or silence it:
```bash
# E.g.:
npm install-scripts approve @parcel/watcher
```
