#### API
# How to plan an API

---
## 1) Goal:
Define the reason of this API exists.
## 2) Where:
What URL this API will be available.
## 3) Endpoints:
What locations with this API that accepts requests and send back responses.
- where/endpoint-name-to-see-all-content (GET)
- where/endpoint-name-to-add-specific-content (POST)
- where/endpoint-name-to-see-specific-content (GET)
- where/endpoint-name-to-update-specific-content (PUT)
- where/endpoint-name-to-delete-specific-content (DELETE)
## 4) Resources:
What resources you want to provide with this API.
