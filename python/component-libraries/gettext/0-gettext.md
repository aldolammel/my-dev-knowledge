# Gettext

---

The gettext module is a core part of Python's standard library that provides internationalization (i18n) and localization (l10n) services for Python apps.

---
## Installation:

**Before:** assuming you're in the project environment!

**Installing:**

Using UV:
```bash
uv add python-gettext
```
Or using APT:
```bash
sudo apt update
sudo apt install gettext     # Check if it's not installable by PIP, for example!
```
