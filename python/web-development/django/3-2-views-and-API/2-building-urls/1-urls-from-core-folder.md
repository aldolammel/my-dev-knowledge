# Core `urls.py` file

---

The `/core/urls.py` file is an autocreated project-level URL router (bunch of endpoints), so it's the file that tells Django when a request comes in with this URL, send it to that app/view! 
Think of it as the traffic controller for the entire project.

All other `/apps/sub_app_name/urls.py` files use this `/core/urls.py` file as router-base.
