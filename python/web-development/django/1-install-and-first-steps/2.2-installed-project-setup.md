- [x] 2.1) (Skip it if you'll use an existent `settings.py` model later or you already did it) Organize the `settings.py` header:

DEBUG = ...

## 5) Create/Bring basic sub-apps in the app:

- [ ] **Before:**
	1. Bring your main Django sub-apps for each case:
		1. Pagex: `.../django/useful-sub-apps/pagex/`
		2. Or Wagtail: [/python/web-development/django/4-cms-admin/3-cms-expansion-wagtail/\_installation](/python/web-development/django/4-cms-admin/3-cms-expansion-wagtail/_installation.md)

- [x] 5.1) (Skip it if you'll use an existent `settings.py` model later or if you already have it configured) Show to Django where will be each template folder in your sub-apps, going to the core-folder `settings.py` file and editing this line in `template` list:
```python
# From:
'DIRS': [],
# To:
'DIRS': [BASE_DIR / 'templates'],
```
