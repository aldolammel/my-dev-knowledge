# Testing the application

---
## Before:

1. Assuming you already got the app installed.
2. If you are using database, assuming the db is running.

---
## 1) Check the installation and current setup:

1.1) Checking the app itself:
```bash
# Using UV:
uv run manage.py check
# Or using only Python:
python manage.py check
```

1.2) Checking if the migration historic is fine:
```bash
# Using UV:
uv run manage.py makemigrations --check --dry-run
# Or using only Python:
python manage.py makemigrations --check --dry-run
```
