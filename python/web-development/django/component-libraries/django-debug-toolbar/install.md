# `django-debug-toolbar` package

---

It adds an overlay panel to HTML pages in your browser, showing what happens behind the scenes on every request/response cycle.

==ARE YOU SURE==
If you are using an external front-end solution (like React, Vue, etc), probably you don't need this Django package.

---
## Installation and integration:
       
**Before:**
- Assuming you already are in the project environment!

Using UV:
```bash
uv add --group dev django-debug-toolbar
```
