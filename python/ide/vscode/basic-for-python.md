## 1) VSCode project settings:

**1.1) In the project folder, create or edit this file:**
```
/your_project/.vscode/settings.json
```

**1.2) In that file, apply these new lines specific for Python projects:**

[/python/ide/vscode/examples/.vscode/settings.json](/python/ide/vscode/examples/.vscode/settings.json)

**1.3) Also, tells VSCode you got some extension recommendations for other project's devs:**

[/python/ide/vscode/examples/.vscode/extensions.json](/python/ide/vscode/examples/.vscode/extensions.json)

**1.4) (If applicable) Make sure your .gitignore file is NOT blocking the .vscode folder and its content in project repository!**
