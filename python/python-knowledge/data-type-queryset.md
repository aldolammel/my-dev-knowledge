# QuerySet

---

`QuerySet` is not a universal programming concept or standard data type but a [Django's](/python/web-development/django/_about.md) terminology for an object representing a database query and its results.

Other programming languages and frameworks have similar concepts, often with different names:

| Language                            | Framework / ORM  | Equivalent concept       |
| ----------------------------------- | ---------------- | ------------------------ |
| [Python](/python/_about.md)         | Django ORM       | `QuerySet`               |
| Python                              | SQLAlchemy       | `Query` / `Result`       |
| Java                                | Hibernate        | `Query` / `TypedQuery`   |
| C#                                  | Entity Framework | `IQueryable<T>`          |
| PHP                                 | Laravel Eloquent | `Collection` / `Builder` |
| [JavaScript](/javascript/_about.md) | TypeORM          | `QueryBuilder`           |
| Ruby                                | Active Record    | `ActiveRecord::Relation` |
