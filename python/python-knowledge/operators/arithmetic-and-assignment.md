```python
x = 10
x + 3      # 13
x - 3      # 7
x * 3      # 30
x / 4      # 2.5 (true division always returns a float)
x // 3     # 3   (floor division — rounds toward negative infinity)
x % 3      # 1   (modulo / remainder)
x ** 2     # 100 (exponentiation)

# Augmented assignment (no ++ or -- in Python)
x += 5     # 15 (also -=, *=, /=, //=, %=, **=, &=, |=, ^=, >>=, <<=)
x += 1     # standard way to increment
```
