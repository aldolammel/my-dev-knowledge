# String formatting

---

```python
text = "Hello World"
print(text.upper())  # HELLO WORLD

name = "john doe"
print(name.upper())  # JOHN DOE
```

```python
text = "Hello World"
print(text.lower())  # hello world

name = "JOHN DOE"
print(name.lower())  # john doe
```

```python
text = "hello world"
print(text.title())  # Hello World

name = "john doe"
print(name.title())  # John Doe

phrase = "the quick brown FOX"
print(phrase.title())  # The Quick Brown Fox
```

```python
text = "hello world"
print(text.capitalize())  # Hello world

name = "jOHN"
print(name.capitalize())  # John
```

```python
text = "Hello World"
print(text.swapcase())  # hELLO wORLD

mixed = "PyThOn"
print(mixed.swapcase())  # pYtHoN
```
