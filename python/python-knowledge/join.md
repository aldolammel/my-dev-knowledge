#### Python > Commands
# `join()`

---

```python
friends = ['Peter', 'Joseph', 'Nick']
friends_formatted = ', '.join(friends)

print(f'Original list: {friends}')
print(f'My friends are {friends_formatted}')

# Output:    Original list: ['Peter', 'Joseph', 'Nick']
# Output:    My friends are Peter, Joseph, Nick
```
