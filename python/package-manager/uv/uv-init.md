#### Python > Package Manager > UV
# `uv init` command

---

It creates the minimal Python project scaffolding, creating automatically some files like `pyproject.toml` and `.gitignore` files. Don't use this from existing projects or models once they would be overriden.

---
## 1) Using the command:

==Attention!==
Don't take any "model" or existing `pyproject.toml` and `.gitignore` yet!

Ask UV to install the minimal Python project scaffolding files:
```bash
uv init
```
